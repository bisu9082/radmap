# Data

## Raw data (not redistributed here)
- **Fukushima airborne survey (JAEA EMDB):** https://radioactivity.nra.go.jp/emdb/
  Download the *Distribution Survey of Radioactive Substances* airborne products for the analysed
  fiscal years (2011, 2012, 2013, 2014, 2015, 2020, 2025). Used in accordance with the original licence.
- **HotSpot detonation field:** generated locally with HotSpot Health Physics Codes v3.1.2
  (2,000 kT surface burst). Place the exported field here (see `src/` for the expected format).

## Processed data (place here)
- Processed dose-rate grids used as interpolation inputs.
- Reconstructed dose-rate grids are written to `../results/`.
